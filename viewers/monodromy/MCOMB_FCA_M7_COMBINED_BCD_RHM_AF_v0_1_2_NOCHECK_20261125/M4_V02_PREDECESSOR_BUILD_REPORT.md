# M4 build report

The M4 successor adds atom-core.js, atom-packet.js, atom-ui.js, extract-atom.cjs and two new verification suites. The browser embeds the same core and packet modules that the arithmetic tests execute. The source extractor pins the unchanged atom HTML and checks its actual function against factorized coordinate contributions.

The assembler adds M4 provenance and its panel inside the existing additive viewer block. Its string insertion uses a replacement callback to preserve JavaScript dollar-sign sequences verbatim. This was caught by the assembled-module byte test during development, before sealing.

The default verifier and seal extend the P1 procedures with M4 suites and dependency pins. Server and endpoint files, inherited arithmetic, spectral.js, spectral-ui.js, existing source controls, family handling and plot/camera interaction bytes stay identical to P1. Existing packet validators are preserved: M4 is an independently replayed sidecar.

The new interface uses exponent sum throughout. It retains independent addresses under planar projection and character kernels, declares exact binding conditions, shows symbolic zero certificates for the accepted collapses, and names the character-order atom of q separately from shell N. Partial drawing and enumeration limits are visible.

Acceptance counts are recorded by the actual executions in PRESEAL_SUMMARY.json and fresh external post-seal receipts. No expected count in this prose substitutes for those executions. Independent audit of M4, seating and lock remain pending.
