# Strict PT1 packet/API shapes

Public gate: replay(bytes, expectedBinding=null) returns PASS with COMPLETE_TORSION, PARTIAL with PARTIAL_TORSION_EVIDENCE, UNAVAILABLE, or REJECTED. A certificate ID hashes the reconstructed certificate. The certificate hashes the canonical packet; parent.sha256 separately hashes literal parent bytes. Source hashes identify bytes, not authorship. expectedBinding must come from an independently rebuilt context, not the imported packet itself.

Packet exact keys: schema, verifier, parent, binding, visits, operations, subgroup, bound, completion, infinitePoints, sourceClaims. verifier names this gate/version and hashes its arithmetic, replay, parser and exact-model source files; replay recomputes them from its actual fixed source registry. parent has bytes and sha256. binding has modelId, normalizationId, markingId, twistId, sourceHash, linkedContextId. Standalone source/linked hashes may be null. Embedded transport has strict keys and carries all model maps, signed differential, marking, twists, six panel identities and sources; PT1 expects the unassessed transport parent, with reduction fields null/empty.

visits are ordered {index,point} entries identical to target-model parent visits. operations are {kind,points,scalar,output}, where kind is ADD, NEGATE or MULTIPLY; non-multiplication scalar is null. O is {infinity:true}; affine coordinates are {x,y} canonical rational strings. No fields may be added to these objects.

subgroup has elements, generators and invariantFactors. A generator is {point,order,primeDivisors}, with the exhaustive distinct prime divisors checked by trial division. bound has witnesses and gcd; each witness has p, modelId, unitDiscriminant, pointsIncludingInfinity. No bound uses null gcd. completion has method and witness: MATCHED_BOUND/null, PARTIAL/null or X3_PLUS_X_EXHAUSTION with the exact reconstructed polynomial/root/square witness defined in pt1-replay.cjs. infinitePoints are replayed only from complete trivial torsion. sourceClaims are bounded {label,value} strings and grant no arithmetic authority.

Linked wrapper exact keys: schema=BSD_POINTS_TORSION_LINKED_V1, linked (the full BSD_LINKED_VIEW_PACKET_V1), and pt1. Import rebuilds linked transport and replays PT1, then obtains current T4 authorization. Derived comparison is rebuilt and not imported as authority. Read-only window.BSDPointsTorsionV1.snapshot() has no commit setter.
