# M4 v0.3 settled implementation decisions

The intake and Opus's v0.2 cold audit govern this additive successor. The audit reports PROSMENON/PASS and no core findings. Its sequencing condition is satisfied. No sealed predecessor was edited. The earlier decisions remain verbatim in M4_V02_PREDECESSOR_OPEN_QUESTIONS.md.

1. The latest per-tooth correction is adopted: an encounter means collinearity with the carrier. Even comb labels are all odd and can coincide opposite it; odd combs split when K is odd. Axis sides use A+cK and signed amplitude per tooth.
2. Signed integral products use Div(abs(t2*s)). This extends the approved positive case without losing the sign from the recorded product or phase. A zero product is universal alignment; zero amplitude separately removes physical axis evidence.
3. Fractional phi3 is display-only BETWEEN_SHELLS. The exact fixed atom remains; no Float64 position is rationalized. During live spin animation, stale exact spin is not reused. The existing exact rational gearbox is supported.
4. Geometry and the current host spectral view are separated. The internal assembly source never supplies a displayed host character order. Manual atom/Cayley import remains available; live shell mode reads the current host directly even if the Cayley store is held.
5. Saved shell contexts reopen held as sidecar views. Reopening does not mutate host controls. Explicit following resumes current host state. All claims are recomputed; edited, rejected and pending state has no current export authority.
6. The encounter log is capped at64 sampled observations, preserves repeated returns, and explicitly counts omissions. It is neither an M6 history graph nor an authenticated historical record. Replay checks each stored context's arithmetic.
7. Complete unsupported factorization/geometry is refused honestly, while independently decidable exact shell facts are retained. The unchanged v0.2 caps and numerical labels apply.
8. Source packages and scratch copies stay immutable during verification; all runtime receipts and screenshots remain outside seals. Full default runs before and after sealing are required. Independent delta audit, seating and lock remain separate.

No unresolved design question blocks this build. PT1 subgroup lattices, Atkin–Lehner actions, root numbers, M5–M7 and P1 coverage improvements remain deferred. 37a1 remains rank>=1 only.

9. The unchanged host centers a newly entered s modulo 2N. Capture follows the committed exact register, not the raw text before that operation. Enter s=20 at N>=20 before walking downward; subsequent shell changes preserve it.
10. The pinned host shell slider uses integer steps and its spectral card asserts integer phi3. This successor does not add a fractional host control. BETWEEN_SHELLS is verified through the adapter capture seam and held packet replay; that defensive path is not a claim that the entire inherited host renderer accepts fractional phi3.

11. The base 3!/s20 browser regression uncovered a pre-existing paired-modulus display exception: its admitted spin range is |s|<=B+1. walk-host.js now makes only implicit current-display calls return null outside that domain, disables that optional overlay and labels the range refusal. Explicit calls and the original verifier still reject out-of-domain input. No formula, supported-domain result, host source bytes or BSD endpoint changes. The shell atom and committed spin remain intact.
