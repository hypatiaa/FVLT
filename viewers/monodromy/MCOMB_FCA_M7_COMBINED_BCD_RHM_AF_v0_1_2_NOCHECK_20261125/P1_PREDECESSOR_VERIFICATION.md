# Verification process

node verify.cjs executes all current viewer, PT1, U1 and P1 arithmetic/browser suites, the disposable historical Cayley regression suites, and the complete inherited T4/T3/T2/T1/schema chain. Every worker writes outside the sealed source and staged packages. node seal.cjs requires an external passing full or v1-only preseal receipt matching the current source inventory. After sealing the complete default must pass again against those exact bytes.

Narrow p1, u1, pt1 and core modes are development subsets and do not qualify a seal. Actual new group counts are in PRESEAL_SUMMARY.json and the external post-seal SUMMARY.json. Independent numerical case counts are reported separately and never added twice. Failures remain failures; fresh retries receive distinct receipts.

The complete verifier preserves source/stage inventories, predecessor manifests and external source pins. The server/security path is unchanged. Builder PASS, Opus cold audit, seating, lock and release are separate standings.
