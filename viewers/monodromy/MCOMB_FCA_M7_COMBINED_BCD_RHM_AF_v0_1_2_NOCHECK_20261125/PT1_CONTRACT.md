# PT1 v0.1 proposed API and mathematical contract

The new formats are BSD_POINTS_TORSION_PACKET_V1 and BSD_POINTS_TORSION_CERTIFICATE_V1. `pt1-group.cjs` supplies exact general Weierstrass arithmetic; `pt1-producer.cjs` supplies untrusted candidates; `pt1-replay.cjs` is the separately callable public gate. `pt1-linked.js` binds that gate to a freshly rebuilt viewer v0.8 transport context. Every packet and derived certificate carries source hashes recomputed from the actual PT1 verifier files. Full export uses BSD_POINTS_TORSION_LINKED_V1 and retains the entire predecessor packet.

Only replay may derive COMPLETE_TORSION and LOCAL_EXACT_TORSION_REPLAY. Membership, exact finite order, a finite subgroup, an upper divisibility bound, partial evidence and unavailable computation have separate outputs. No submitted status grants authority. Complete group invariants must pass Mazur's list as a hard consistency guard, never as a completeness proof.

The general chord/tangent formulas are those in the pinned PT1 mathematical handoff. Replay checks membership, exact order minimality at every prime divisor, a bijective cyclic-product enumeration, inverses and the full closure table. For each distinct odd prime 3..1009 it checks primality, p-integrality, unit discriminant and the point count including O. Rational torsion injects into each such reduction, hence divides the gcd. Equality of this bound and the subgroup size proves completeness. Neither a failed point search nor a non-tight gcd does so.

Trusted theorem inputs: [Poonen, Computational aspects of curves of genus at least 2, section 5](https://math.mit.edu/~poonen/papers/ants2.pdf), and [Mazur, Modular curves and the Eisenstein ideal (1977)](https://www.numdam.org/item/PMIHES_1977__47__33_0/). The [Sage torsion documentation](https://doc.sagemath.org/html/en/reference/arithmetic_curves/sage/schemes/elliptic_curves/ell_torsion.html) documents the non-tight-bound limitation. No Sage execution is asserted.

The deliberately narrow exhaustive fallback is for the exact model [0,0,0,1,0], bound 4, subgroup {O,(0,0)}. Replay reconstructs x(2P)=(x²−1)²/(4x(x²+1)), checks the exceptional denominator branch, the exhaustive rational 2-torsion roots of x(x²+1), and the only candidate preimage x=±1 with y²=±2. Exact rational-square checks exclude both. There is no general division-polynomial completeness implementation; other non-tight bounds remain PARTIAL with that missing obligation stated.

For 37a1 [0,0,1,-1,0], complete trivial torsion plus exact nonidentity (0,0) yields INFINITE_ORDER_POINT_WITH_COMPLETE_TORSION and the separate ALGEBRAIC_RANK_LOWER_BOUND value 1. This never supplies algebraic_rank, exact rank, a basis, saturation, heights or regulator. Small exact multiples are display data, not the proof.

Limits: inherited canonical 96-digit rational components and 16,384-bit intermediates; signed scalar magnitude <=4096; 50,000 group additions per gate; <=32 subgroup elements, <=2 generators, <=32 good-prime witnesses, <=24 visits, <=32 recorded operations, <=16 infinite-order candidates; public PT1 packet <=2 MB. Search is bounded (default x=-8..8, plus caller candidates); no unsuccessful search is a negative result. Resource exhaustion returns UNAVAILABLE. Malformed or false proofs return REJECTED. Exact point checks remain independent of global minimality and period placement.

All six linked bindings, source bytes, twist lineage, exact maps, normalization and signed differential, marking, context and ordered visits are retained and replayed. Unique subgroup elements never deduplicate visits. A rational period address is complex torsion, not E(Q); carrier rationality and the zero-role gate are unchanged. PT1 does not match imported points to phase addresses; that is P1.

The server and fixed /assess endpoint remain byte-identical to v0.8. PT1 replay is browser-local, separately hashed, and not covered by the T4 response signature. A live T4 partial result may bind context without global minimality. Offline/file mode clears derived PT1 authority while retaining exact local operations. Worker output cannot commit directly; the consumer replays it against the current rebuilt packet. Epoch checks surround asynchronous work. Full packet import replays all mathematics and current transport; source torsion claims remain visible and cannot supersede locally verified complete torsion.

Optional bad-prime cross-check A5 is deferred. P1, heights, exact rank/basis/saturation, analytic work, rhombic placement, Fourier coefficients/Sturm, twists, primitive characters/Gauss sums and character-weighted L-values remain later deliverables. Builder PASS, independent cold audit, seating and lock are separate.
