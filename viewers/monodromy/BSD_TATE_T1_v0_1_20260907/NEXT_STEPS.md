Only then certify global minimality, Neron normalization, the curve bad-prime list and the full conductor/Tamagawa product. A missing local branch or cofactor prevents the corresponding global certificate.

6. **Heights.** First validate numerical local heights using minimal/local data, then rigorously bounded local terms with remainder/error proofs. Use the larger BSD canonical height `H(P)=lim 4^-n h_x(2^n P)` and pairing `(H(P+Q)-H(P)-H(Q))/2`. Certify no regulator from an arbitrary point list: independence, saturation/full-basis and rank remain separate. No Sha order inferred from BSD becomes an independently proved order.

The point/import path is independent of minimality. The chosen local-height route needs the local reduction foundation and its own correct local-height formulas; a Tamagawa number alone does not compute a height.
