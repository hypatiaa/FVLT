# Exact finite FCA proof note

## Contexts
The atom is the product of exponent chains 0..a_i with integer label product p_i^e_i. Birkhoff objects and attributes are positive prime powers. Incidence is b does not divide g. Intersections of attribute columns are exactly downsets of this disjoint union of chains; their lcm labels run through Div(N), with empty lcm 1. Extent inclusion preserves labels.
Ordinal LE columns are e_i ≤ k for 0 ≤ k < a_i. Their intersections are principal ideals. Ordinal GE columns are e_i ≥ k for 1 ≤ k ≤ a_i; intersections are principal filters. GE extent inclusion reverses the filter generator label. These contexts have product(a_i+1) concepts.
Nominal columns fix one exponent. Intersections are coordinate faces, plus empty for nonempty coordinate families. Each coordinate is free or one of n_i values, giving product(n_i+1)+1 concepts for N>1. For N=1 there is one object and no attributes, hence one concept. A nominal column is a hyperplane; a complete strand fixes all coordinates except one, so a separate strand context is built.

## Closure and enumeration
For an object set E, the intent consists of all columns containing E; intersecting those columns gives E double prime. Empty intersections mean all objects. NextClosure enumerates closed object masks in lectic order with an explicitly bounded number of closure calls. A concept cap or closure cap yields PARTIAL, never a complete lattice or complete cover diagram. In a complete enumeration, x<y is a cover exactly when no third enumerated extent lies strictly between them. Canonical extent IDs contain the ordered object IDs; they are not positions in a picture.

## Strand certificate
There are r prime coordinates. Each address lies on r strands. Two distinct addresses share exactly one strand iff they differ in one coordinate. Therefore B B^T=rI+A. Positive semidefiniteness gives the lower bound -r. In each coordinate use u=(1,-1,0,...,0). Its sum is zero, and f(e)=product u_i(e_i) is nonzero with every strand sum zero. Thus B^T f=0 and Af=-r f, attaining the bound. The coordinate zero-sum spaces have dimensions n_i-1; the common kernel is their tensor product, of dimension product(n_i-1). N=1 uses the empty tensor 1, r=0, empty B columns and A=[0]. The identity, lower bound, witness and multiplicity are separate record fields. Matrices are only materialized within the matrix budget; the combinatorial certificate is independent of drawing.

## Action and walks
Canonical residue translation is declared extra structure. It transports nominal attributes by adding the same coordinate residue, and transports strands by translating their fixed coordinates. Both incidences are invariant. Every nonzero translation moves the unique least divisor 1, hence is not an ordinal-poset automorphism. Zero translation is identity. Ordinal context records never claim a residue-translation automorphism. Prime labels remain fixed; no unlabelled coordinate-permutation count is asserted.
Group edges are x→x+c v for each original tooth c, including repeated actions and zero letters. Order annotation uses coordinatewise comparison and labels equal, ascending, descending, or incomparable without changing that operator. Ascent edges increment exactly one nonmaximal coordinate, have no wraps and change the operator. Their adjacency is nilpotent under exponent-sum order, unlike the generally nonzero translation spectrum. A bounded explicit tree preserves the exact word; truncation retains a displayed subset and a complete-through-depth marker.

## Transforms
The divisor zeta transform sums f(a) over a|d. Möbius inversion on exponent chains has factor 1 at equal exponents, -1 at a one-step difference, and 0 beyond one step. Multiplying coordinate factors gives μ(d/a), recovering f exactly. Group characters instead diagonalize tooth translations with eigenvalue sum_c exp(2πi c sum_i k_i v_i/n_i). The phase descriptor is exact; displayed trigonometric values are Float64, not bounded.
Partitioning all Q-th roots by exact order gives sum_(d|Q) c_d(k)=Q[Q|k]. Möbius inversion gives c_Q(k)=sum_(d|gcd(Q,k)) d μ(Q/d), computed as exact integers. This helper concerns uniform full-root sums, not an arbitrary comb and not BSD evidence.
