# M7 scope decisions
1. Preserve old export schemas. Like M4–M6, M7 uses an own sidecar containing the schema §15 fcaRecord rather than adding an unknown nullable field to sealed V1 envelopes. This preserves strict predecessor replay.
2. Default LE; GE explicitly reverses natural labels. Context, graph and transform selectors remain independent. An extent selects prime powers in Birkhoff and divisors otherwise.
3. Large contexts give exact analytic counts where proven, selected face cardinalities and the combinatorial strand certificate. They do not pretend that an unenumerated concept lattice is complete. Complete-strand context concept counts are derived only from complete enumeration.
4. Ascent has coordinate letters, not tooth letters, because it is a different transition operator. Equal transitions in the group walk receive EQUAL (including zero letters); wraps may be descending or incomparable.
5. The selected face is a separate nominal-coordinate inspection, even when an ordinal context is selected. It does not change that context's incidence or pretend to be its selected concept.
6. Diagram arrows run upward with extent inclusion or exponent sum. Prime-strand edges are undirected. Geometry is a rendering, not an incidence oracle.
7. M6 O1 is handled by one transparent timeout-only retry with first failure evidence retained. M6 O2 is the cumulative-cell-limit clarification. Neither changes M6 arithmetic.
8. Independent audit, seating, lock and release remain distinct. Contact sweep and point-placement coverage remain separate work.
