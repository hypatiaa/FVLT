# M5 local-structure inspector 0.1

Additive successor to audited M4 v0.3. Start node server.cjs (or launch.ps1), open its printed localhost URL, and expand Local structure beneath the atom explorer. The panel is dormant until opened.

Choose integer labels, a valid simple quotient, or the current atom's complete prime strands. Inspect an exact scalar address or exponent tuple; choose boundary offset t and a five-position start u. Use selected address links the existing Cayley or atom inspection. Neighbor buttons move only the structure inspection, not the host source or atom orbit.

The panel shows the induced neighborhood graph, triangles through the selected address, ordered adjacent-neighbor pairs, opposite-neighborhood boundaries, and full-graph clique bounds. A maximum is certified only when the witnessed lower bound meets the justified upper bound. Search work runs in a worker and can be cancelled and resumed within declared limits. A partial result remains a bound, not a maximum.

S1 and S2 are named detached structure fixtures. They do not change the main source or introduce a general free-frequency host mode. S1 displays 10100 over integers and 10101 modulo19. S2's integer graph is triangle-free while its mod19 graph contains the clique {0,3,11}.

Export structure setting writes an independent M5 JSON sidecar. Reopening recomputes the source and certificate, then stays HELD. Follow current source explicitly resumes the current source. A source hash identifies data, not historical authenticity. Graph and spectral results supply no BSD evidence; 37a1 stays rank >= 1 only.

The existing M4, T4/PT1/U1/P1 arithmetic and UI modules, server and cameras are preserved byte-for-byte. The additive M5 UI adds the small explanation beside M4 that newly typed s is re-centred modulo2N; SPIN-EXACT-001 was already repaired. The contact-sweep panel remains a separate queued deliverable, as do M6/M7 and the other previously deferred work.

Run node verify.cjs for full qualifying verification before sealing and again after sealing. node verify.cjs m5 is a narrow development check and cannot qualify a seal. No receipts are written into sealed packages. Preserve sibling dependencies when transferring this folder.
