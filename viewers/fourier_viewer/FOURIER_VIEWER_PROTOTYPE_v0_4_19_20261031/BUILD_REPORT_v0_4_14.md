## Change (SCHEMA_ADDENDUM_22.md; README v0.4.14 section with dial ledger)
- **Mask = walk weight 0 / 1 / 2** (the α_Tilt pattern): `comb-numeric.compute(st, opts)` takes `opts.mask`; absent, the v0.4.13 code path. Weight 1 where N/2 ± c·t₂ are both prime, **2 on the c = 0 tooth** (equal pair, when N/2 is prime), 0 elsewhere. The pen is exactly the kernel's G_N(s) (Cor II.23.5c).
- **Setup** (convention B, the note's): integer mode, B = N/2 − 1, φ₃ = 0, t₁ = n₆ = 1, α = 0, t₂ = 2 when N/2 is odd (odd m = a_max + 1, c = a_p/2), t₂ = 1 when N/2 is even (even m = a_max + 1, c = ±a_p), m = 3 when a_max = 0 (N = 4). m ≤ 720 for every even N ≤ 1,448 (max m = 719); N = 1,450 outside.
- **Track "Goldbach N ▸"**: last option of the CA preset menu (after "n²+1 shells ▸"); a menu of even N = 4 … 1,448 (`gb_sel`, first option "◂ CA presets") replaces the CA menu. Entering from the CA menu opens N = 24 (or the current N if already on a Goldbach shell). **No new visible control**: counts 39/41/39/41, 39 on the track, both viewports, all three drawing tabs. The track ends when any dial leaves the preset.
- **Address `&gb=1`**, written only while the track is on, after the `ca` / `sq` positions. Reading: exactly `gb=1`, once, on a state sitting exactly on the preset of an even N, 4 ≤ N ≤ 1,448, α_Tilt absent; anything else refuses the flag only, with a status label ("Goldbach track flag refused: …"); never combined with `ca=1` / `sq=1`. N is derived from the state (B, φ₃), so no N field is needed. Example tail: `…&tab=fourier&view=&gb=1`.
- **Tilt handling: both.** While the track is on, a nonzero α_Tilt from any control is **REFUSED** (state unchanged, status line "α_Tilt is refused while the Goldbach track is on: …", a label in the α drawer; α_Tilt = 0 allowed). **Entering** the track from a state with α_Tilt ≠ 0 **switches it off** with the status line "Goldbach track on: α_Tilt switched off (was …)". An address `&tilt=…&gb=1` refuses the flag with a label. The core also refuses (compute returns a reason).

Same pen (G_4 = 2e^{iπs}); the unmasked comb differs from the script's at N = 4 only.

4. The exports (exact JSON, state, CSV, Lift JSON, pair) do not carry the mask; the track exists in the address only. The stats text gains one Goldbach line.
