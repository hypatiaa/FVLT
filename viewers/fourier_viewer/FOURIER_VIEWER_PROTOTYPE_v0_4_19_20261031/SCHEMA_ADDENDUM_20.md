# SCHEMA ADDENDUM 20 (v0.4.12, 2026-10-21): log radius display of the Fourier view (display only)

No change to the state schema, the exact export, the Lift JSON, the PNG export, the address id (`fv-comb-hopf/0.2`) or any exact readout. Reason (saphir): in the flat plane the two halves of the full stack span 1/N … 1 and 1 … N, so they cannot both be legible; with Reciprocal winding on, one half was off-screen (alpha = -1) or a few-pixel blob (alpha = +1). The fix is saphir's own log mirror (Farey helix explorer v2/v3: value x drawn at radius |ln x| about the throat 1/1), laid flat.

1. **The item.** Layers menu of the Fourier view: "Log radius (throat at |z| = 1)", shown only while Full stack is on (like the reciprocal item), off by default. View key `fl`, written only when on; with the Full stack off a stored key is inert. Clifford and Hopf are unchanged (they already show both halves). Visible control counts stay 39 / 41 / 39 / 41.
2. **The map.** Every point the Fourier view draws (stack dots, reciprocal dots, teeth, walk, carrier, the radius circle and polygons, the fraction stack) keeps its exact phase arg z and is drawn at radius R(r) = R_t (1 + ln r / L), r = |z|, R_t the on-screen throat radius, L the largest |ln r| among the drawn stack points (both halves when Reciprocal winding is on, otherwise the shown half; if every stack point has r = 1, L is set to 1 and the caption says so). So r = 1 sits on the throat circle, r = e^{+-L} at 2 R_t and 0. The frame is fitted to the drawn log picture (at least the throat).
3. **Mirror.** With the reciprocal layer on, R(1/r) = 2 R_t - R(r): the two halves are exact mirror images about the throat circle (checked in test-v0412 and browser-check-v0412).
4. **Rings (choice).** Log rings at r = e^k for integer k, every ceil(floor(L)/6)-th k (k = +-1, +-2 … when L <= 6), radius R_t(1 + k/L), labelled "e^k"; the linear polar grid is replaced by them. The throat circle |z| = 1 is drawn (dashed) and labelled "throat |z| = 1".
5. **Degenerate cases, never silent.** Points with ln r < -L are clamped to the centre and counted in the caption (stack points cannot be, since L covers them; walk, teeth and fraction points can); points with r = 0 (n6 = 0) have no log image: drawn at the origin, counted and labelled.
6. **Caption.** "log radius display: radius drawn as ln|z| about the throat |z| = 1 (display only; exact values unchanged)" plus the formula, L and the counts. With the reciprocal layer on its caption says the halves are mirror images about the throat (instead of the planar-inversion remark).
7. **Byte identity.** With `fl` absent every state, address, export, caption, about text, canvas and PNG equals v0.4.11 (browser-check-v0412). With `fl` on, the five exports equal those of `fl` off (the address key aside).
8. **Code.** `instruments/comb-hopf/view-fourier.js` only (`logModel`, `logR`, a drawn copy `D` of the comb; `stackLayer` takes the mapped arrays); `build/package.cjs` version string. `panel-g-robin.js`, `panel-bd.js` untouched.
9. The walk's first vertex (the origin, W_0) is not counted as a point at r = 0; only teeth, carrier, later vertices or stack points at the origin are (all of them only when n6 = 0).
