# SCHEMA ADDENDUM 19 (v0.4.11, 2026-10-21): reciprocal winding (throat at 1/1), the other half of the full stack (display only)

No change to the state schema, the exact export, the Lift JSON, the PNG export, the address id (`fv-comb-hopf/0.2`) or any exact readout. Sources: `FULL_STACK_MIRROR_HALF_DESIGN_NOTE_v0_1_20261021/NOTE.md` (sha256 0f2dc093…690b6) and its addendum `FULL_STACK_MIRROR_HALF_DESIGN_NOTE_v0_1_1_20261021/ADDENDUM.md` (3591c7dd…69aab), with saphir's decision (the reciprocal half) and the owner's choices for Q2–Q8 below.

The design note v0.1 presented this as candidate A among alternatives; that framing was wrong: the mirror of a given set is determined, and N^{α/N} is a separate construction, not the other half (correction relayed by saphir, 2026-10-21).

1. **The layer.** "Reciprocal winding (throat at 1/1)" is the other half of the full stack: its image under the inversion w ↦ 1/w̄ (radius 1/ρ = N^{−α}/|n₆|; phases unchanged and exact). On the Hopf base it is the exact reflection through the equator plane (heights −(ρ²−1)/(ρ²+1)); it is the Farey half x = 1/n → 0, i.e. t = ln x < 0. The equator |w| = 1 is the throat. It coincides with the α ↦ −α stack only when |n₆| = 1, and both halves start on the equator only when |n₆| = 1 (otherwise at heights ±(n₆²−1)/(n₆²+1), mirror images). Prior work: saphir's Farey helix explorer v2/v3 (toggle of the same name, x ↦ 1/x). Arithmetic: x ↦ 1/x is the divisor ↔ cofactor exchange m ↔ (n²+1)/m, the same involution as the dashed diameter of the Poincaré disk card (unchanged in this version). It is not the viewer's "Mirror axis" (c ↦ −c, fibre-side); Prop II.23.9c G3 forbids conflating them, so the word "mirror" is not used for this layer.
2. **Controls.** One item per existing Layers menu (Fourier, Clifford, Hopf base), "○/◐ Reciprocal winding (throat at 1/1)", shown only while that view's Full stack is on, off by default. View keys `fr`, `cr`, `hr`, written only when on (a v0.4.10 reader refuses them as unknown view keys, the SCHEMA_ADDENDUM_17 pattern). With the Full stack off a stored key is inert. Visible control counts stay 39 / 41 / 39 / 41.
3. **Q2.** True inversion w ↦ 1/w̄ (A1), not the α ↦ −α stack; the about text and README say they agree only for |n₆| = 1.
4. **Q3.** A layer drawing both halves at once (the α dial alone shows one side at a time).
5. **Q4, Q5.** The Poincaré disk card is unchanged (its dashed diameter already is this involution). No new disk toggle.
6. **Q6.** Clifford: the two halves share the existing head budget (12,000 − m): ⌊(12,000 − m)/2⌋ heads each, same host selection for both, so drawn heads never exceed the single-stack budget. The caption says when thinned. With the layer on the primary half also uses the half budget (it is thinned earlier than with the layer off). Near-pole clipped points of the reciprocal leaf are counted in the caption, not hidden.
7. **Q7.** Hopf base: offered in both charts. Host chart: the exact reflection (x, y, −z) of each point's image. Comb chart (w = W/ρ_cur): the reflection of the drawn image, labelled as the image of ρ_cur²/z̄ (not of 1/z̄). Chosen as the simpler honest option (no idle line).
8. **Q8.** Name: "Reciprocal winding (throat at 1/1)", about line citing the explorer v2/v3 (sha256 3c10ff5f…d00bdc43 and 49c1ac19…1663f745 as pinned in the addendum).
9. **Per view.** Fourier: points z/|z|² on the same canvas bitmap (signature gains `|R`), frame grows to include the larger half, dashed unit circle "throat |z| = 1", caption says the planar separation is not a certificate. Clifford: leaf 1/ρ_N, amplitudes swapped, phases kept (not an isometric copy; ρ ↦ 1/ρ swaps the circle lengths). Hopf: fromAffine of the inverted point, packed once per (stack, chart scale); label separation transfers unchanged because reflection is an isometry (note checks C1, C2).
10. **Registers.** Phases exact (the stack's residues, untouched). Radius 1/(n₆·N^α): exact rational for integer α, numerical otherwise (labelled). Drawing float64. n₆ = 0 has no image: counted, labelled, not drawn.
11. **Byte identity.** With `fr`, `cr`, `hr` absent every state, address, export, caption, about text, canvas and PNG export equals v0.4.10 (checked in `build/browser-check-v0411.cjs`). Display only: the layer enters no export, readout or card.
12. **Code.** `host-core/stack-core.js` gains `reciprocal(P)` and `liftHalf(st,P,stereo,recip,budget)` (existing `lift` untouched; `liftHalf(…, false, full budget)` equals it exactly). `panel.js` gains three lazy model getters (`stackR`, `stackLiftHalf`, `stackLiftR`). `view-fourier.js`, `view-clifford.js`, `view-hopf.js` gain the item, action, key and drawing. `panel-g-robin.js` and `panel-bd.js` untouched.
