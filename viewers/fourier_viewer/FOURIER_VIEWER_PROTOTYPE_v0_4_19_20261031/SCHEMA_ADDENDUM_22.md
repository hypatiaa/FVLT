# SCHEMA ADDENDUM 22 (v0.4.14, 2026-10-21): the Goldbach prime-pair track "Goldbach N ▸" (display only)

No change to the state schema (`fv-comb-hopf-state/0.2`), the exact export, the Lift JSON, the PNG export, the address id (`fv-comb-hopf/0.2`) or any exact readout of an existing state. Source: `GOLDBACH_PRIME_PAIR_MASK_DESIGN_NOTE_v0_1_20261021/NOTE.md` (sha256 4f2d1c9ca33933620057c85515901f08ff969aac7fe17c4ae72ad6198c5ef99a) and its check `scripts/check_prime_pair_mask.cjs` (ALL PASS), with saphir's decisions 1-7 (the note's leans). Kernel: Cor II.23.5c, Rmk II.23.5b, Def-Prop II.23.5d (v3.2.6 text).

1. **Module.** `host-core/goldbach-core.js` (fv-goldbach-core 0.1.0, global `FVGoldbach`), exact register: integers only, primality by exact trial division (N ≤ 1,448). Reads comb-core `offsets` only. `host-core/comb-numeric.js`: `compute(st, opts)` takes an optional `opts.mask` (integer walk weights per tooth in offset order); without it every line is the v0.4.13 code path (byte-identical output, checked against the v0.4.13 core on 18 states incl. tilt).
2. **The mask is a walk weight** (precedent: α_Tilt, addendum 15). w_c = 1 when N/2 + c·t₂ and N/2 − c·t₂ are both prime, w = 2 on the c = 0 tooth when N/2 is prime (the equal pair p = N/2, counted twice in G_N), w = 0 elsewhere (the tooth is *ghosted*). With it the pen is **exactly** the kernel's G_N(s) = Σ_{p ∈ P_N}(e^{2πips/N} + e^{2πi(N−p)s/N}) = e^{iπs}R_N(s), R_N(s) = 2Σ cos(2πa_ps/N), for every real s. Σ w_c = 2g(N), so G_N(0) = 2g(N). The numerical bound of a masked walk is doubled (weights up to 2). The tooth rays are the unweighted z_c; the walk step of the c = 0 tooth is 2z₀. The latitude-gate residual in the cards reads the first tooth, not W₁ (W₁ may be 0 when the first tooth is ghosted).
3. **Setup per N** (even, 4 ≤ N ≤ 1,448): integer mode, B = N/2 − 1, φ₃ = 0 (viewer shell N/2), t₁ = 1, n₆ = 1, α = 0, α_Tilt = 0, and **convention B**: t₂ = 2 when N/2 is odd (all a_p even; odd m = a_max + 1; c = a_p/2, so the unmasked comb is exactly the odd candidate pairs), t₂ = 1 when N/2 is even (all a_p odd; even m = a_max + 1; c = ±a_p); m = 3 when a_max = 0 (N = 4: t₂ = 1, one tooth c = 0 and the candidates c = ±1). m ≤ 720 for every even N ≤ 1,448 (max 719); N = 1,450 is outside the track.
4. **The track** is a UI overlay on integer mode like CA and n²+1: the CA preset menu gains a new **last** option "Goldbach N ▸" (after "n²+1 shells ▸"); the Goldbach menu `gb_sel` (first option "◂ CA presets", then N = 4, 6, … 1,448) replaces the CA menu in the same place. Entering from the CA menu opens N = 24 (or the current N if the state already sits on a Goldbach shell); choosing N sets the dials of item 3 and keeps s. No visible control is added: counts 39 / 41 / 39 / 41, 39 on the track. The track ends when any dial leaves the preset (the mask is derived from N, not free state), by the base buttons, or by a hash change.
5. **Address.** Optional last field `&gb=1`, written only while the track is effectively on, after the `ca` and `sq` positions (the three never occur together). Reading: exactly `gb=1`, once, on a state that sits exactly on the preset of some even N with α_Tilt absent. Anything else is refused for the flag only (the state loads as the address says, track off, status label "Goldbach track flag refused: …"): repeated or not exactly `gb=1`; together with `ca=1` or `sq=1`; not integer mode / φ₃ ≠ 0; N outside 4…1,448; a dial left the preset; α_Tilt ≠ 0. A v0.4.13 reader refuses an address with this key (unknown key handling as for `ca` / `sq`: the flag is split off before comb-core, so comb-core itself is unchanged). Every other state writes the address it wrote in v0.4.13.
6. **α_Tilt on the track — refused, and switched off on entry.** (a) While the track is on, a nonzero α_Tilt entered by any control is **refused**: the state does not change, the status line reads "α_Tilt is refused while the Goldbach track is on: …", the α drawer shows a label; α_Tilt = 0 is allowed. (b) **Entering** the track from a state with α_Tilt ≠ 0 **switches α_Tilt off** and the status line says "Goldbach track on: α_Tilt switched off (was …)". (c) An address with `&tilt=…&gb=1` refuses the flag with the label. A product weight would not be G_N.
7. **Ghosted teeth.** The teeth the prime filter removes are drawn ghosted and labelled "removed by the prime filter: N/2 ± c not both prime" (caption line, role `gb-caption`), never hidden, and do not enter the pen. Fourier: a faint dashed ray and ring (`tooth-ghost`, `tooth-ghost-dot`), the hit target kept; the walk and its vertices pass through the kept teeth only. Clifford: **all** branches on the one leaf ρ = 1 (the balanced Clifford torus); kept branches ±a_p/t₂ solid (both mirror branches), removed ones as faint thin orbits (`orbit-ghost`) and small hollow dots (`tooth-dot-ghost`); mirror-meeting marks only for kept pairs. Hopf base: the pen on the carrier page (the amber walk through the kept teeth), ghost trails (`trail-ghost`) and dots; no new claim. The phasor table marks kept rows "weight w" and removed rows "ghost" (dimmed, `data-gb`).
8. **Goldbach card** (cards column, before Phasors; only on the track): N, shell and convention, g(N) = #P_N and "G_N(0) = 2g(N)" (exact), the pen sentence, s, R_N(s) (numerical, ± bound; G_N = e^{iπs}R_N), the page (carrier / carrier + π / "|W| ≤ bound … not certified zero"; floats never certify a zero; "G_N ≡ 0 (empty fibre, exact)" when P_N is empty), the equal-pair line (δ), the pair list (p, N − p), a_p with both branch chips (raw (N/2, ∓a_p), primitive ×1, type, k = p or N − p; the equal pair ×(N/2), unknot), first 8 pairs with "more" / "collapse". Printed guards, kernel v3.2.6 wording without markdown marks: Interference register, Empty-fiber guard, Unit-fiber guard (Def-Prop II.23.5d), "Closure reaches conjugation, not Goldbach." (Rmk II.23.5b), the Cor II.23.5c status line, and the line that the comb walk for m ≥ 3 is instrument-tier. Λ_G(N) and the coprime reference are **not shown** (they stay in the released v11.21.3 panel).
9. **Prior art** (in the about text of the card and of each view): the correspondence was stated earlier in `GOLDBACH_COMB_CORRESPONDENCE_v0.2.md` (2026-07-20) and Codex's `goldbach_clifford_adapter_v0_7_1.html`. Nothing is ported from either.
10. **Export.** The exact JSON, state, CSV, Lift JSON and pair exports do not carry the mask (it is derived from N); the stats text gains one Goldbach line while the track is on. PNG export is unchanged in mechanism (the caption lines are in the image).
11. **Byte identity.** With the track off, every state is byte-identical to v0.4.13: stage, canvas, caption, about, cards, address, hash and the five exports (`browser-check-v0414`, incl. the Goldbach shells without the flag and with tilt), the CA and n²+1 tracks, PNG export.
