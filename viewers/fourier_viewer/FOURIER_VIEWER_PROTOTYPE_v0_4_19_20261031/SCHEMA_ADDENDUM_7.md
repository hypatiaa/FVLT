## F7: the cyclotomic-field definitions (recorded here as schema)

- **generated field ℚ(ζ_L):** L = lcm over the nonzero-amplitude teeth of the order of e^{iπ·k_c·s/N}. This is the field generated by the **phase factors** e^{iπ·k_c·s/N}; that is the addendum-5 definition. **[Correction, Sol via saphir, 2026-10-13]** It is not necessarily the field of the full phasor values z_c = ρ·e^{iπ·k_c·s/N}, because the amplitude ρ = n₆·N^α can be irrational. For example, N = 2, α = 1/2, n₆ = 1 and s = 0 give phase factors 1 but phasors √2. The earlier wording "the minimal field of the current phasor values" was wrong. The old host's note "generated field of the nonzero phasor values" has the same flaw, and the rebuild does not copy it.
- **phase container ℚ(ζ_C):** for s = p/q in lowest terms, C = 2·q·N·L_k, where L_k = lcm of the denominators of the k_c (L_k = 1 when every k_c is an integer).
  - It is the fixed field that contains e^{iπ·k·s/N} for every k in (1/L_k)ℤ.
  - It is a container convention, not a minimal field.
  - When L_k = 1 it equals the old host's "ambient" (`ℚ(ζ_{2qN})`, frozen host L6406), and the export says `host_ambient_equivalent: true`.
- **Reference values:** at the reference state, generated ℚ(ζ₁₄) and container ℚ(ζ₅₆).
- **Labels:** "generated by the phase factors" and "phase container (convention)". **[Corrected, Sol via saphir, 2026-10-13; it was "generated (minimal)".]** Where ρ is irrational, the ⓘ says that the phasor values themselves may need the further extension ℚ(ζ_L, ρ).
