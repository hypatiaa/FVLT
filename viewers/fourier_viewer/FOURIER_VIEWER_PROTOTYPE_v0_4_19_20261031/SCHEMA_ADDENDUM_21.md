# SCHEMA ADDENDUM 21 (v0.4.13, 2026-10-21): the pen stays linear in the log radius display (display only)

No change to the state schema, exports, Lift JSON, PNG export, address id or any exact readout; view key `fl` as in addendum 20. Reason (saphir, owner's lean): the pen's steps are tooth vectors added tip to tail; a log map destroys vector addition, so in v0.4.12 the walk collapsed to a short dashed line along an axis.

1. **Stack only.** With `fl` on, only the stack layers (Full stack, Reciprocal winding), their throat circle and log rings are log-mapped, exactly as in v0.4.12 (the stack canvas is byte-identical to v0.4.12 in the tested states; logModel unchanged).
2. **Pen on a linear scale.** The pen (walk, vertices, trace, endpoint ring), the teeth, the carrier, the radius circle, the amber/witness polygons and the fraction points are drawn on the ordinary linear scale about the same origin (the plane origin), with their own scale s_pen. Choice: s_pen = R_t / (2 e_pen), e_pen = max(rho, |W_t|, |z_c|) over the pen: the pen's largest extent is drawn at 1/2 of the throat radius R_t (if e_pen = 0, s_pen = R_t). The drawn pen is a similarity image (one scale, same directions) of the linear walk; each drawn step vector equals the drawn tooth vector.
3. **Scale bar and labels.** Bottom right of the picture a bar of length u*s_pen pixels, u a nice number (of `nice`), labelled "pen u" (data-role `pen-scale`, `pen-scale-bar`; data-u, data-len, data-pen-sc; the log-radius element also carries data-pen-sc, data-pen-ext). Short in-picture labels only (longer text goes behind the (i) by the existing rule), so the caption has two lines: "log radius applies to the stack only; the pen, teeth and carrier are drawn on a linear scale (their own scale bar)" and the scale-bar line with s_pen in units of R_t per unit |z|.
4. **Frame.** The frame is fitted to the stack only (ext = max(1, largest stack display radius)). The pen is inside 1/2 R_t. data-clamp is always 0 now (no pen point is log-mapped); r = 0 stack points are counted as before.
5. **Byte identity.** `fl` off: identical to v0.4.12 (and so v0.4.11) in all states tested. Code: `instruments/comb-hopf/view-fourier.js` (the drawn copy D is the exact numerical comb; XP, YP, scP), `build/package.cjs` version string.
