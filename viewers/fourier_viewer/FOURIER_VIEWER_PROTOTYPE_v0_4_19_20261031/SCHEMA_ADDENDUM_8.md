Date: 2026-10-14. Decision: saphir, "I choose b" (relayed in `../FOURIER_VIEWER_HANDOFF_FABLE_CONTINUOUS_N_20261014/HANDOFF.md`). Brief: `BUILD_BRIEF_v0_3_CONTINUOUS_N_20261014.md`. ## 1. Framing (handoff §1; Lumen's correction in `On_papers_track/NOTE_instrument_as_lifted_DFT_2026-10-07.md`)

Continuous N is the variable moved along at fixed s, not a new arithmetic object. Moving N between shells recovers ratios of shells (ALG-3), not k. Nothing in the instrument says more than that. Between two integer shells the shell arithmetic (Wilson, gearbox residency, divisors, contrast, bracket, SPREAD stops, the fraction stack, the integrality gates) is undefined and is switched off with one label.

## 2. Keys and validation

| Key | Values | Default | Notes |
|---|---|---|---|
| `nMode` | `integer`, `continuous` | `integer` | new dial key; in `DIAL_KEYS` (before `phi3`), `DEFAULTS`, the address, the state export, the exact export (`state.nMode` and `exact.nMode`), the Lift JSON (`nMode`) and the dial ledger |
| `phi3` | integer mode: an integer 0 … B+1 (unchanged). Continuous mode: an exact rational 0 ≤ φ₃ ≤ B+1 | `23` | continuous mode accepts `7/2`, `3.5`, `0`; the stored text is the exact lib's canonical text (`3.5` is stored as `7/2`; an address carrying `phi3=3.5` is refused as non-canonical) |

`resolve(st)` returns, besides the old fields:
- `Nq`: the exact rational B + 1 − φ₃, always;
- `N`: the BigInt when `Nq` is an integer, else `null`;
- `Nint`: whether `Nq` is an integer;
- `phi3q`: the exact rational φ₃; `phi3` is the BigInt when φ₃ is an integer, else `null`.

Every exact phasor computation uses `Nq`. Every integer-only readout tests `Nint`. N ≤ 0 stays the empty state (N = 0 is reached in continuous mode by φ₃ = B + 1 exactly; negative N is outside the range).

## 3. The label

Verbatim, one source (`comb-core.js` `BETWEEN`), with the actual fraction:

> between shells: N = p/q; shell arithmetic undefined

Where it appears when `Nint` is false: every tab's warning line (caption role `degenerate`, never ellipsized); the Wilson card (in place of both readouts and the gearbox rows); the Divisors card; the Shell card; the fraction-stack caption ("fraction stack idle — " + label); the exact export (`exact.betweenShells`, `exact.wilsonN`, `exact.gearbox`, `exact.shell.status`, `exact.divisors.label`); the Lift JSON gate `integral_frequencies` (status `NOT_EVALUATED`, reason = label) and the `prime_pair` reason (suffix). Gearbox code between shells: `BETWEEN_SHELLS`, `eligible: false`, every residency field `null`; the m-only facts φ(m), defect and the primality of m are still stated.

## 4. What stays exact with rational N

k_c = Nq·t₁ + c·t₂; tooth phases k_c·s/Nq mod 2 and their orders; carrier t₁·s (+1 when n₆ < 0) and offset −c·t₂·s/Nq; the ALIGN flag (t₁·s ∈ ℤ) and the SPREAD flag (the existing formulas with Nq); the S³ lift phases; orbit windings (rates cleared by the common denominator), gcd reduction, knot type and the exact closure period lcm(2/|t₁|, 2·Nq/|c·t₂|) (2·Nq/|c·t₂| = 2a·d/(b·|n|) for Nq = a/b, c·t₂ = n/d). The closure period stays in the record (orbit `period`, branch `closurePeriod`, Lift `closure_period_s`) also when the drawing is a partial window.

## 5. Stepping (R20) and the wrap gate (R21)

- Between shells, in comb mode (m ≥ 3, integer nonzero gears), the SPREAD families are **refused (4e)** with the reason "SPREAD needs an integer gearbox: N = p/q", never approximated. ALIGN (s ∈ ℤ/|t₁|) stays active. The step record carries `refused: [{kind: 'SPREAD', source: '4e', reason}]` and its label ends with "; SPREAD refused (4e): …". The s row shows the refusal line before any press. PAIR (m = 2) is unchanged. All other 4e refusals are unchanged.
- R21 gate: the same logic over Nq. The wrap by 2N is invariant iff every drawn k_c is an integer and, for the S³ lift, Nq·t₁ and c·t₂ are integers. With rational N the gate usually closes (s_eff = s_typed, "kept: wrap not invariant here"). Example of an open gate between shells: N = 7/2, t₁ = t₂ = 2, m = 3 (k_c = 7 + 2c, N·t₁ = 7); typed s = 9 gives s_eff = 2.

## 6. Phase container, generalised (a convention)

Derivation. Let N = a/b and s = p/q in lowest terms and L_k = lcm of the denominators of the k_c. Each k_c = j/L_k with j ∈ ℤ, so

k_c·s/N = (j/L_k)·(p/q)·(b/a) ∈ (1/(L_k·q·a))·ℤ,

and every phase factor e^{iπ·k_c·s/N} is a (2·q·a·L_k)-th root of unity. The phase container is ℚ(ζ_C) with

**C = 2·q·a·L_k**.

For an integer shell, a = N and this is the old C = 2·q·N·L_k. It is a container convention, not a minimal field. `host_ambient_equivalent` is true only when N is an integer and L_k = 1. The generated field, "generated by the phase factors" ℚ(ζ_L), L = lcm of the orders of e^{iπ·k_c·s/N} over the nonzero-amplitude teeth, is unchanged. JSON (`cyclotomic_field`): `N` (exact text), `N_integer`, `a`, `phase_container_factor` (`2qN`, `2qN*L_k` on a shell; `2qa*L_k` between shells), `phase_container_formula` (`C = 2*q*N*L_k` on a shell; `C = 2*q*a*L_k (N = a/b in lowest terms)` between shells). Example: N = 7/2, t₁ = t₂ = 1, m = 3, s = 1/3: k_c = 5/2, 7/2, 9/2, L_k = 2, a = 7, q = 3, C = 84, generated ℚ(ζ₄₂).

## 7. Registers (R7)

ρ = n₆·N^α is numerical, computed from the float of Nq. The numerical bound is 8·(m + 2 + |α|(1 + |ln N|))·ε·max(ρ, 1), ε = 2⁻⁵²; |ln N| = ln N on every shell (N ≥ 1), so the bound is unchanged there; N < 1 occurs only between shells. `rho_irrational` is decided exactly: with N = a/b and α = p/r in lowest terms, ρ is irrational iff n₆ ≠ 0, N ≠ 1, r > 1 and a or b is not a perfect r-th power. No exact readout is taken from a float.

## 8. Controls (panel)

- **Mode switch:** one toggle button in the φ₃ row, `aria-pressed` (true = continuous), text `N∈ℤ` / `N∈ℚ`. One toggle, not two buttons: two buttons would make 41 visible controls at the default state (the cap is 40, ⓘ excluded).
- **Continuous mode:** the φ₃ slider step is 1/100 of a shell (its two-decimal value is read exactly); integer shells are marked on the track (when B + 1 ≤ 1000); ◀ ▶ snap to the next integer shell in their direction (in integer mode that is φ₃ ± 1 as before); ⏮ unchanged; a φ₃ exact box appears beside the label (Enter applies; decimal or fraction; refused with the reason outside 0 … B+1); Play ▶ N advances 1/100 of a shell per tick (one shell per tick in integer mode).
- **Switching** continuous → integer with a non-integer φ₃ rounds to the nearest shell (a tie j + 1/2 goes to j + 1, the smaller N) and says so in the message line, for example "N continuous → integer: φ₃ = 7/2 rounded to the nearest shell φ₃ = 4 (N = 21)." Integer → continuous changes no value.
- The shell readout shows N as the exact fraction.

## 9. Schema versions and the upgrade rule

| Record | Was | Now |
|---|---|---|
| address (`#v=`) | `fv-comb-hopf/0.1` | `fv-comb-hopf/0.2` |
| state export | `fv-comb-hopf-state/0.1` | `fv-comb-hopf-state/0.2` |
| exact export | `fv-comb-hopf/0.1` | `fv-comb-hopf/0.2` |
| Lift JSON | `fv-comb-hopf-lift/0.2` | `fv-comb-hopf-lift/0.3` (adds `nMode`, `N`, `N_integer`) |
| pair JSON | `fv-comb-hopf-pair/0.1` | `fv-comb-hopf-pair/0.2` |

The exact export carries `exact.N` (exact text), `exact.N_integer`, `exact.nMode`, `exact.betweenShells` (the label or null) and `state.nMode`. The state export carries `nMode` inside `state` (no derived values).

**The only upgrade rule:** a `fv-comb-hopf/0.1` address (which has no `nMode` key) is read as `nMode = integer`, every other key as stored; the page then shows it as its 0.2 address. A 0.1 address that carries an `nMode` key is refused. State and exact JSON files of schema 0.1 are refused as an unknown schema (they are not upgraded).

The build-pins block in the page keeps its own id (`fv-comb-hopf/0.2`, unchanged since v0.2).
