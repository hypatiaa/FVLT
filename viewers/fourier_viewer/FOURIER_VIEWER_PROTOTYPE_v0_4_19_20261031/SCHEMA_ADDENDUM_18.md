2. **Card "Branch primitivity (trial division)"** (Panels group B, read-only, no buttons, starts collapsed). At integer N ≥ 2, gears (1, 1), odd m with comb(m) ⊇ {2, …, ⌊√N⌋}: N prime ⟺ every branch c = 2…⌊√N⌋ has g_c = gcd(N, c) = 1 ⟺ no UNKNOT among them (both forms shown, agreement checked). N = n² + 1 is highlighted (⌊√N⌋ = n), any other integer N works. Refusals (no verdict, reason given): N ≤ 0 or non-integer; gears not (1, 1); even m; N = 1; m too small (missing c listed, capped at 12). Notes: c = ±1 reads UNKNOT ×1 for every N (refuted criterion O13); c = 0 repeats N times; −c mirrors c; n₆ = 0 makes ×g a formal label. Kernel: Def II.23.9, Lemma II.23.9a guard G3; the v3.2.7 (locked) erratum G4 = the Lemma II.23.9a G4 winding note (unreduced k_c equals rendered k_c/d iff d = 1 or k_c = 0), cited as supporting the ×g reading. Repeated lines capped at 8 ("⋯ j more"). Not in the exact export.
3. **Card "Poincaré disk · Farey layer and divisor orbit"** (Panels group B, collapsed, own canvas 480×480 inside the card; no tab, no control). Genuine Poincaré disk by ζ = (z − i)/(z + i) (gauge w = i, no recentring). Scope: the current integer shell's Farey layer F(a) (kernel Lemma II.5g: reduced e/n_i, 1 ≤ e ≤ n_i − 1, n_i = a_i + 1 for N = ∏ p_i^{a_i}), its contact edges (Def II.5h), isolated beads, Ford horocycles; plus Astra's points ζ = (k − m − 2n·i)/(k + m + 2), k = N/m, cosh d(0, ζ) = (k + m)/2, for every divisor m of N when N − 1 = n² (else a labelled idle caption). Background: the two-coloured modular tessellation (each Farey triangle = six (2, 3, ∞) triangles, coloured by the parity of the PGL(2, ℤ) reflection word). Only the representative point per divisor (no Γ∞ translates). The (3, 4, ∞) orbifold is the S⁶ track's and is not drawn.
   - Exact (BigInt over ℚ(i)): cusp images ((p² − q²) − 2pq·i)/(p² + q²); edge centre (a − ib)(c − id)/(ac + bd), radius 1/|ac + bd| (diameter when ac + bd = 0); Astra's ζ, cosh d, and an SL(2, ℤ) matrix γ with γi = (n + i)/m (searched for m ≤ 10⁶). Drawing (float64): arcs, horocycles, fills, the depth cut-off.
   - Credit: the disk idea is saphir's; the divisor-orbit construction is Astra's written mathematics (classical parametrisation, Musicantov–Zehavi arXiv:2112.07494 §1.2–1.3). No novelty, nothing about cancellation, sieve weights, Landau or primes is shown (note §4 kept in the card).
4. **Pairing.** Each card says in one line that the two cards show the same divisors of N two ways (winding repetition; orbit points on Farey edges).
5. **Collapsed start.** Panel modules may carry `collapsed:true`: closed unless the saved open state says otherwise (`pn` unchanged). The strip's "Open panels" opens them too; "Collapse panels" closes everything. Every other card keeps its v0.4.9 default.
6. **Track "shells n² + 1".** A UI overlay on integer mode, like CA, reached through the CA preset menu (its new last option "n²+1 shells ▸"); then a menu `sq_sel` (first option "◂ CA presets", then n = 1…359 → N = n² + 1) replaces the CA menu in the same place. Choosing n sets B = n², φ₃ = 0, m = 2n + 1 (so N = n² + 1 and comb(m) holds c = 2…n); the gears are left as they are (the branch card gates on them). The track ends when the state leaves B = n² (n ≤ 359), integer mode, or a mode button is pressed.
   - **Address key** (written only while the track is on, after `&ca=1`'s position; the two never occur together): `&sq=1`. Example `#v=fv-comb-hopf/0.2&…&sq=1`. Reading: exactly `sq=1` on integer mode with B = n², 1 ≤ n ≤ 359, once; anything else is refused for the flag only (state loads as the address says, track off, status label "n²+1 track flag refused: …"). `ca=1` and `sq=1` together: the CA flag stands, the sq flag is refused. A v0.4.9 reader refuses an address with this key (see BUILD_REPORT_v0_4_10 for what it does).
   - Controls: no visible control is added (the CA menu gains one option; the n menu is shown only on the track, in the place of the CA menu). Counts stay 39 / 41 / 39 / 41 and are 39 on the track.
7. **Byte identity.** With no `&sq=1` every state, address, exact export (JSON, state JSON, CSV, Lift JSON, stats), caption, about text, canvas and PNG export, and the Fourier, Clifford and Hopf tabs, are byte-identical to v0.4.9. The Panels tab differs only by the two new collapsed `<details>` elements. The instrument panel DOM differs by the hidden `sq_sel` and the extra option in the (hidden) CA menu.
